3 · LLM 接入

用于兴趣解析与论文精排。若暂不配置，可显式选择「纯关键词模式」降级启用。

第一次配置？这里有完整教程（含各厂商入口与免费额度）
  1. 选一家厂商。国内服务器建议用能直连的： DeepSeek（推荐）· 通义千问· 智谱 GLM· Moonshot
  2. 注册 → 实名认证 → 领赠额或充值（多数厂商新用户有赠额）。
  3. 在控制台的「API Keys」页创建密钥，只显示一次，立刻复制。
  4. 粘贴到下方表单，点「保存并测试连接」——通过才会进入下一步。
厂商Base URL（填到 /v1 为止）建议模型
DeepSeekhttps://api.deepseek.com/v1deepseek-flash / deepseek-chat
通义千问https://dashscope.aliyuncs.com/compatible-mode/v1qwen-turbo / qwen-plus
智谱 GLMhttps://open.bigmodel.cn/api/paas/v4glm-4-flash
Moonshothttps://api.moonshot.cn/v1moonshot-v1-8k
硅基流动https://api.siliconflow.cn/v1Qwen/Qwen2.5-7B-Instruct
OpenAIhttps://api.openai.com/v1gpt-4o-mini

Base URL 不要填到 /chat/completions，程序会自己拼。任意 OpenAI 兼容端点 （vLLM、LM Studio、OneAPI 等）同样适用。
不想配置就点下面的「纯关键词模式」——但中文描述的召回会明显受限。 完整图文教程见仓库 docs/guides/llm-api-key.md。
