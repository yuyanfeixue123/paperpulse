4 · 邮件通道（必配）

无可用邮件通道将无法发送验证邮件与每日推送，此步不可跳过。
第一次配置邮件？这里有注册入口与 DNS 记录清单
  1. 选一家服务商。Brevo 免费 300 封/天（约支撑 300 名活跃用户），是容量最大的免费选项。
  2. 注册并验证发件人账号（不验证无法发信）。
  3. 在发信子域上添加 DNS 记录：SPF、DKIM、DMARC（见下表）。
  4. 创建 API Key 或 SMTP 密码，填入下方表单。
  5. 下一步会当场发一封测试邮件，收到才算配好。
通道入口额度角标
Brevo（推荐）brevo.com300 封/天有
Resendresend.com3000 封/月无
阿里云 DirectMaildm.console.aliyun.com按量无
AWS SESaws.amazon.com/ses$0.10/1000无

阿里云 SMTP 参数：服务器 smtpdm.aliyun.com，端口 465（SSL）， 用户名 = 完整发信地址（如 paper@mail.你的域名），密码在「账户中心 → SMTP 密码」设置。 25 端口是明文且云厂商 TOS 不鼓励，建议用 465。
DNS 记录（以发信子域 mail.你的域名 为例）： MX mx01.dm.aliyun.com（阿里云）； TXT v=spf1 include:spf1.dm.aliyun.com -all； TXT _dmarc.mail.你的域名 → v=DMARC1; p=none; rua=mailto:dmarc@你的域名。 完整图文教程见仓库 docs/guides/email-delivery-setup.md。

下一步之后可在「后台 → 邮件」发送测试邮件验证配置。
